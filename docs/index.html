A closer look Optional details about this demonstration+

The circles are servers. Their role can change; their names stay the same. Arrows show who is talking, and the label above them tells you what is being sent.

This is an educational browser model of Abhinesh Dahal’s Raft key/value project in Go. It is not a live Go cluster. Timing is slowed; labels are illustrative locations. The runnable Go demo retains protocol state in simulated, in-memory storage. It does not provide real disk durability.

The browser experiment uses five fixed members, crash/restart, and per-server connection loss. It omits snapshots and full read execution, and deduplicates one app request at a time for clarity. The Go service uses version checks and can return an uncertain result after a lost reply.
