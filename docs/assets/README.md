# Local assets

- `inter-variable.woff2`: Inter variable font from
  https://rsms.me/inter/font-files/InterVariable.woff2. SIL Open Font
  License 1.1, included as `inter-license.txt`.
- `ibm-plex-mono.ttf`: IBM Plex Mono Regular, distributed by Google Fonts
  at https://fonts.gstatic.com/s/ibmplexmono/v23/-F63fjptAgt5VM-kVkqdyU8n5ig.ttf.
  SIL Open Font License 1.1, included as `ibm-plex-license.txt`.
- `map.svg`: contiguous-US country outline derived from Natural Earth's
  public-domain 1:110m country geometry:
  https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson.
  Coordinates use a simple equirectangular projection for a quiet illustrative
  backdrop. Server cards represent illustrative regions, not real deployments.
- `favicon.svg`: original mark for this demo.

The site makes no external asset requests. Inter supplies the interface
type; IBM Plex Mono distinguishes values, versions, and log entries.

Design research: https://raft.github.io/ (guided Raft explanation and optional
log inspection), https://rsms.me/inter/ (interface typography), and
https://www.ibm.com/plex/ (technical typography). The UI and scenario code
were written for this project; no third-party visualization code is used.
